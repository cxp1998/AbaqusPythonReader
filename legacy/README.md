## English

This directory archives the original **ABAQUS-PythonReader** executable and decompiled C# reference project from 2010.

### Contents

- `PythonReader_2010.exe`: The classic 2010 executable published by Dr. Jiao (.NET Framework WinForms).
- `csharp_v1/`: Decompiled C# project and source code for architectural reference and study (intermediate build binaries cleaned).

### Acknowledgments

Our heartfelt thanks go to the original author, **Dr. Jiao** (Email: [ck436@126.com](mailto:ck436@126.com)), for his pioneering work in 2010. This modern rewrite inherits the core HUD and journal monitoring concepts while re-engineering the application using a modern Python + PySide6 stack.
