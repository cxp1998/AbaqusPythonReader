# Legacy PythonReader (2010 Version)

本目录归档了 2010 年原版 **ABAQUS-PythonReader** 的原始可执行程序与反编译参考源码工程。

## 目录内容

- `PythonReader_2010.exe`: 2010 年由焦博士编译发布的经典原始可执行程序（.NET Framework WinForms 架构）。
- `csharp_v1/`: 原版程序的反编译工程与 C# 源码，供学习与架构参考（已清理所有中间编译二进制文件）。

再次衷心感谢原作者**焦博士**（Email: [ck436@126.com](mailto:ck436@126.com)）在 2010 年的开拓性设计。PythonReader 2.0 在继承其核心功能理念的基础上，使用现代 Python + PySide6 技术栈进行了全面重构。
