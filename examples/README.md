<a id="english"></a>
## English

This directory contains sample replay journals used for testing and demonstrating AbaqusPythonReader.

- `sample_abaqus.rpy`: A realistic Abaqus replay journal containing 3D solid part extrusion modeling, material assignment, section creation, and viewport operations (pan, rotate, zoom, fitView).
  - Test syntax highlighting and color themes.
  - Test the "Filter viewport operations" feature in action.

<a id="chinese"></a>
## 简体中文

本目录包含用于测试与演示 AbaqusPythonReader 的样例文件。

- `sample_abaqus.rpy`: 包含三维零件拉伸建模、材料截面赋予、视口平移/缩放/旋转操作的典型 Abaqus 脚本回放流。
  - 可用于测试语法高亮着色效果。
  - 可用于测试“过滤视口操作（pan/rotate/zoom/fitView）”开关的功能表现。
